# pure-growth テーマ

## トップページ「クライアント一覧」の更新手順

日本地図のエリアボタンとモーダルの中身は、すべて自動生成されています。
HTML を直接書き換える必要はありません。

### 1. クライアントを追加する

**記事（クライアントボイス）がある会社**

WordPress 管理画面で通常どおり投稿するだけです。

1. 投稿を新規作成し、カテゴリーに **クライアントボイス（`client-voice`）** を指定
2. カスタムフィールド **`voice_region`** に都道府県を選択
3. 公開する

→ 保存した時点でキャッシュが破棄され、トップページに即反映されます。
   表示名は `voice_name` があればそれを、無ければ記事タイトルを使います。
   `meta_noindex` が ON の場合はリンクなしのプレーン表示になります。

**記事が無い会社（名前だけ載せたい）**

`template/data/client-extra.php` に追記してコミットします。
ダミー投稿を作る必要はありません。

```php
return array(
    'hokkaido' => array(
        '株式会社ウッディークラフト',                                  // リンク無し
        array( 'name' => '篠河建設㈱', 'url' => 'https://example.com/' ), // リンク有り
    ),
);
```

会社名の末尾の「様」は自動で付きます。
同じ名前が投稿側にもある場合は投稿側が優先され、二重に出ることはありません。

### 2. 都道府県・エリアを編集する

`template/data/client-areas.php` が唯一の正です。
都道府県の追加・削除・並び順・エリア名の変更は、このファイルだけを直します。

`front-page.php` や `template/modal-area*.php` を触る必要はありません。

> スラッグは ACF の `voice_region` の選択肢と完全に一致させてください。
> 一致していない都道府県はモーダルに表示されません。

### 3. 見出しの「◯◯社以上」

実際の掲載件数に自動で追従します（10社単位で切り捨て、下限100社）。
クライアントが 110 社を超えれば自動的に「110社以上」になり、
件数が下限を割っても表記が下がることはありません。

下限や刻みを変えたい場合は `front-page.php` の
`pg_client_headline_count( 100, 10 )` の引数を変更してください。

## 関連ファイル

| ファイル | 役割 |
|---|---|
| `template/data/client-areas.php` | エリア／都道府県マスタ（唯一の正） |
| `template/data/client-extra.php` | Git で管理する追加クライアント名簿 |
| `inc/client-map.php` | データ取得・集計・キャッシュ |
| `template/modal-area.php` | モーダル本体（全エリア共通） |
| `template/modal-area01〜06.php` | 後方互換用の薄いラッパー |
| `front-page.php` | 地図セクションとモーダルのループ生成 |

---

## デプロイ

`main` ブランチに push すると、既存の GitHub Actions
（`.github/workflows/deploy.yml`）が FTP でテーマを本番へアップロードします。
設定は既に済んでいるので、追加の作業はありません。

このリポジトリのルートが `wp-content/themes/pure-growth/` に対応します。
